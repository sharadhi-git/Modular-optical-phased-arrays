# Modular IR Optical Phased Array – Simulation Codes

This repository contains **Mathematica simulation codes** used in the following
peer-reviewed journal and conference publications by **Sharadhi Gunathilake et al.**

The purpose of this repository is to support **research transparency and reproducibility**.
Only simulation codes are provided. Published articles are linked below as references.
